I checked all 16 images from the first set against where each is used. **Five are WhatsApp-only on screens that cover more than WhatsApp**, so they need new versions. The other 11 stay as they are (table at the bottom).

**How to make them**
- **Use a new ChatGPT chat.** Attach 2–3 of your current images (the login phone, the rocket and the megaphone work well) and start with: *"Match the exact style of these images for everything in this chat."*
- **No text and no logos** in any of them. Channels are shown by colour and shape only:

  | Channel | Colour | Shape |
  |---|---|---|
  | WhatsApp | lime green #91C82B | speech bubble |
  | Instagram | pink #F74770 | heart |
  | Meta Ads | orange #FF7518 | megaphone or rising bars |
  | AI | purple #A66BFF | four-point sparkle |

- **Save each with the file name in its heading** and drop them in `~/claude-assets`.
