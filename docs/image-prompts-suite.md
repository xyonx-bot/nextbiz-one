| **NextBiz AI** | the assistant | purple #A66BFF |

Background warm off-white **#F7F3EB**, highlights yellow **#FFD21F**, text dark ink **#1A1D23**.

**How to use**
- **Use a new ChatGPT chat for this set.** Attach 2–3 images from set 1 (for example the rocket, the megaphone and the phone) and start with: *"Match the exact style of these images for everything in this chat."*
- **Sizes:** square 1024×1024, landscape 1536×1024, portrait 1024×1536.
- **No logos anywhere:** not ours (I add the real one) and not WhatsApp's or Instagram's (trademarks). Channels are shown by colour and simple shapes (speech bubble, heart, megaphone, sparkle).
- **Save each file with the name in its heading** and drop them in `~/claude-assets` like last time.

**The shared style.** It's already inside every prompt; paste it again if the style drifts:
> *Soft 3D illustration, rounded chunky shapes, smooth matte surfaces with gentle gradients, soft studio lighting from top-left, soft contact shadows, pastel-bright palette, clean and premium, generous empty space.*

**What changes in the app:** images 1–2 replace the current sign-in art, and 3–7 are new. Images 8–13 are for your website, and 14–16 are for reels and link previews. Set 1's spot illustrations stay as they are.
